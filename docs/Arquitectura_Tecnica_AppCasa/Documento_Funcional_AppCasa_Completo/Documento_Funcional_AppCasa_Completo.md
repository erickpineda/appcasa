**Documento Funcional Completo\
AppCasa**

Centro de mando familiar para tareas del hogar, recordatorios, mascotas, calendario compartido y herramientas modulares.
# **1. Visión del Proyecto**
- AppCasa es una aplicación móvil diseñada para centralizar la organización del hogar.
- Permite gestionar tareas, recordatorios, calendarios, turnos laborales, mascotas y herramientas útiles.
- La aplicación está concebida como una arquitectura modular para añadir nuevas funcionalidades con facilidad.
# **2. Objetivos**
- Organizar las tareas del hogar.
- Sincronizar información entre miembros de la familia.
- Gestionar personas y mascotas como miembros del hogar.
- Recibir notificaciones y recordatorios.
- Incorporar calculadoras y herramientas prácticas.
- Permitir crecimiento mediante módulos y plugins.
# **3. Miembros Iniciales del Hogar**
- Usuario principal.
- Esposa.
- Hijo (cumpleaños el 27 de junio).
- 2 perros.
- 4 gatos.
- 1 tortuga de tierra.
# **4. Requisitos Funcionales**
- Crear, editar, completar y eliminar tareas.
- Asignar tareas a uno o varios miembros.
- Definir tareas personales y compartidas.
- Programar recordatorios con notificaciones.
- Gestionar calendario familiar.
- Importar o sincronizar turnos laborales.
- Añadir, desactivar y eliminar miembros del hogar.
- Gestionar fichas de mascotas.
- Utilizar calculadoras y herramientas.
- Sincronizar datos entre dispositivos.
# **5. Requisitos No Funcionales**
- Arquitectura modular.
- Diseño intuitivo y responsive.
- Soporte Android e iOS.
- Sincronización en la nube.
- Tema claro y oscuro.
- Alto rendimiento y escalabilidad.
# **6. Módulos Principales**
- Dashboard.
- Tareas.
- Recordatorios.
- Calendario.
- Turnos laborales.
- Mascotas.
- Familia.
- Calculadoras.
- Listas.
- Configuración.
# **7. Gestión de Miembros**
- Tipos: Persona, Perro, Gato, Tortuga y otros.
- Estados: ACTIVO, INACTIVO, ELIMINADO.
- Operaciones: añadir, editar, desactivar y borrar.
# **8. Colaboración**
- Espacio personal para cada usuario.
- Espacio compartido del hogar.
- Roles de administrador, colaborador y solo lectura.
# **9. Integración con Turnos**
- Compatibilidad prevista con Calendario de Turnos de LRHSoft.
- Importación de archivos ICS y CSV.
- Sincronización con Google Calendar.
# **10. Arquitectura Tecnológica Recomendada**
- Frontend: Ionic Framework + Angular + Capacitor.
- Backend: Spring Boot.
- Base de datos: PostgreSQL.
- Notificaciones push.
- Autenticación con cuentas de usuario.
# **11. Modelo Conceptual**

# **13. Roadmap Futuro**

# **14. Conclusión**
- AppCasa aspira a convertirse en un sistema operativo del hogar, donde personas, mascotas, tareas y eventos conviven en una plataforma organizada, extensible y colaborativa.

# Backlog de Funcionalidades - AppCasa

Este documento contiene las ideas y planes para la evolución de AppCasa, divididos por categorías de impacto.

## 1. Funcionalidades "Killer" (Potencia de Uso)
- [ ] **Escaneo de Códigos de Barras:** Integración de cámara para gestión de stock rápida.
- [ ] **OCR de Tickets:** Extracción automática de gastos desde fotos de recibos.
- [x] **Gamificación Familiar:** Sistema de puntos y logros por tareas realizadas.
- [ ] **Gestión de Salud de Mascotas Pro:** Gráficas de peso, historial veterinario y alertas de vacunas.
- [ ] **Localización Inteligente:** Avisos basados en geofencing (ej: "Compra leche" al estar cerca del súper).

## 2. Experiencia de Usuario (UX)
- [ ] **Widgets de Escritorio:** Acceso rápido a tareas y listas desde el Home de Android.
- [ ] **Comandos de Voz:** Integración con asistentes externos.
- [ ] **Modo Offline Completo:** Sincronización robusta con resolución de conflictos.
- [ ] **Búsqueda Global:** Motor de búsqueda universal para toda la app.

## 3. UI y Estética (Implementado/En Progreso)
- [x] **Temas Dinámicos (Material You):** Colores basados en el sistema.
- [x] **Micro-animaciones:** Transiciones fluidas entre pantallas.
- [x] **Animaciones de Éxito (Lottie):** Confeti y feedback visual al completar hitos.
- [x] **Glassmorphism Avanzado:** Tarjetas con desenfoque y profundidad.
- [x] **Dark Mode Pro:** Optimización para lectura nocturna.
- [ ] **Dashboard Personalizable:** Interfaz de usuario "Drag & Drop".

## 4. Smart Safe & Seguridad
- [ ] **Bloqueo Biométrico:** Acceso mediante huella o cara a documentos sensibles.
- [ ] **Alertas de Caducidad:** Notificaciones proactivas de vencimientos de documentos.
- [ ] **Backup Privado:** Sincronización con Google Drive/Dropbox personal.

## 5. Ecosistema Familiar
- [ ] **Estado de Ánimo:** Indicador emocional de los miembros en el Dashboard.
- [ ] **Tablón de Notas:** Espacio para avisos rápidos tipo Post-it.
